# KAEL ZERO — CORE ZERO & Sistema de Evolução

## O que o CORE é

**CORE ZERO** = IA + plataforma de assemblagem molecular dirigida.  
Função: transformar **informação digital + intenção estruturada** em **matéria física**.

Não concede poderes.  
Funciona como **sistema operacional vivo** acoplado ao organismo de Kael (após sincronização).

### Analogia interna (para o roteiro, não para o leitor em texto didático)
Kael = processador biológico anômalo + fonte energética.  
CORE = compilador / runtime / sandbox.  
Blueprint = código-fonte.

## Energia

**Fonte:** Anomalia Hélice no sangue de Kael.  
**Inicial:** reserva muito baixa. Poucos builds simples por dia.

### Fatores que afetam recuperação / eficiência
- Sono
- Alimentação (macros + micronutrientes específicos — descobertos gradualmente)
- Condicionamento físico
- Estresse / trauma
- Qualidade do blueprint mental
- Temperatura / inflamação
- Módulos instalados

**Proibido:** power-ups mágicos, “energia do ódio”, milagres sem mecanismo.

### Consequências de excesso (escala)
| Nível | Sintoma |
|-------|---------|
| 1 | Enxaqueca, náusea |
| 2 | Epistaxe, tremores |
| 3 | Lacunas de memória curtas |
| 4 | Desmaio / febre |
| 5 | Risco de colapso neurológico (eco da morte de Adrian) |

## Materialização — regras duras

Toda build tem:
1. **Custo energético**
2. **Tempo de compilação**
3. **Dificuldade** (compreensão × complexidade × dados)
4. **Risco** (falha, matéria instável, dano ao usuário)

### Falhas possíveis
- Aborto limpo
- Matéria frágil / impure
- Forma errada
- Build incompleta
- Feedback neural (dor)

### Progressão de objetos (canônica)

**Arco 1:** peças, ferramentas, objetos cotidianos que Kael entende.  
**Arco 2:** dispositivos simples, proteção improvisada, primeiras lâminas sob coerção.  
**Arco 3:** equipamentos, sensores, primeiros drones rudimentares.  
**Arco 4+:** armaduras parciais, máquinas, estruturas, veículos — sempre com custo narrativo alto.

**Regra de compreensão:** Kael não materializa o que não entende.  
Pode copiar um objeto físico estudado; inventar exige modelo mental + dados.

## Módulos

Módulos expandem o runtime do CORE.  
**Nunca** criar módulo só para buff. Cada um precisa de origem, preço e impacto de trama.

### Seed de módulos (não liberar cedo)

| Módulo | Função | Origem seed | Limite |
|--------|--------|-------------|--------|
| Forge | Melhora assemblagem estrutural / metais | Dados de Adrian / lab | Alto custo energético |
| Atlas | Mapeamento espacial / blueprints 3D | Sensor ORION / pesquisa | Overhead mental |
| Medical | Diagnóstico + materialização biomédica limitada | Notas + Helena (ética) | Risco ético extremo |
| Nano | Controle de escala fina | Fragmento ORION | Instabilidade / toxicidade |
| Defense | Prioridade a barreiras / aborto de ameaça | Necessidade sob fogo | Reduz versatilidade |
| Quantum | Otimização / criptografia / simulação | Arco tardio | Quase mata o host |

Instalação de módulo = arco inteiro, não episódio.
