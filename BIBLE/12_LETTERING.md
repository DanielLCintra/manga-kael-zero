# Lettering — Revista #1

## Regra absoluta
Cada balão de fala tem **rabicho (tail)** apontando para a **boca / cabeça** de quem fala.  
Narration box = retângulo sem rabicho.  
SFX = fora de balão.  
HUD/CORE = tipografia mono, sem balão de fala (ou balão retangular técnico).
