# KAEL ZERO — Formato Obrigatório de Capítulo

Antes de escrever: ler `00`–`08` e atualizar mentalmente a continuidade.

---

## Pipeline (sempre nesta ordem)

### 1. Planejamento
- Número do capítulo / arco
- Objetivo emocional + objetivo de plot
- O que planta / o que paga
- O que NÃO pode acontecer ainda (anti-aceleração)
- Estado de energia / módulos / segredos (do tracker)

### 2. Objetivo em 3–5 linhas
Por que este capítulo existe na franquia (não só “o que acontece”).

### 3. Breakdown por páginas
Para **cada página**:

| Campo | Conteúdo |
|-------|----------|
| Página # | — |
| Quadros | quantidade |
| Descrição cinematográfica | ação + blocking |
| Enquadramento | por quadro ou dominante |
| Iluminação | — |
| Expressões | — |
| Diálogos | PT-BR, natural |
| Narração | só se necessário (preferir show) |
| Efeitos sonoros | — |

### 4. Prompt de IA por página
Prompt **extremamente detalhado** da página inteira:
- incluir prefixo da bíblia visual
- descrever layout de painéis
- personagens, poses, props
- texto dos balões (ou espaço para lettering)
- consistência com páginas anteriores

### 5. Atualização de continuidade
Após o capítulo aprovado/gerado: atualizar `05_CONTINUIDADE.md` e `08_MISTERIOS.md`.

---

## Regras de página

- Abrir com gancho visual ou pergunta
- Fechar com cliffhanger ou virada emocional
- Máximo 1 “aula” científica por capítulo; preferir descoberta dramatizada
- Humor: 1–2 beats, nunca matar tensão do mistério
- Diálogo: subtexto > exposição
